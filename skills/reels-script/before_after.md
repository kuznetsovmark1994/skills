# Правки автора: было → стало

Калибровка хранится в локальном author-profile.md рядом с материалами проекта. Для каждой подтверждённой правки запиши: исходную фразу, версию автора и правило, которое из этого следует.

Новая правка одного ролика становится общим правилом только по подтверждению автора или при повторении. Личный профиль и статистику не включай в публичный пакет скиллов.
