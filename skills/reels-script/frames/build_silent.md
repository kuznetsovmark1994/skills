# Каркас: стройка без голоса

Одна камера, место растёт под музыку, подписи «год · этап». Голоса и истории нет: «красивая стройка, фоновая музыка
и подписи с датами, всё» . 27–63 с. Сценарий здесь = список подписей + план кадров (скилл `reels_epochs`).

по кадру, подписать в первые 2 с («Гиза»). На долгой стройке вместо календарного года — «Год N стройки» или имя
этапа. Подпись говорит то, чего кадр не показывает: «Начинается стройка» под кадром начала стройки — угаданная (С4).
