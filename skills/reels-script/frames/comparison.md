# Каркас: сравнение (матч по раундам)

Две стороны, раунды со счётом, у каждой своя сила. 60–85 с.

> ✍️ **Заполнить под себя.** Эталон автора для этого типа: ролик, длина, досмотр, где лежит текст. Агенту: впиши после первой публикации ролика этого типа.

| Доля | Бит | Что | Ходы |
|---|---|---|---|
| 0–10% | Хук | польза «за вас» + двое героев + доказательство теста | Х6, Х1 |
| 10–12% | Ставка | «Как думаешь, кто победит?» | С1 |
| 12–48% | Раунды | «название → аргументы → вердикт», счёт растёт, штамп на вердикте | Д3, К11, С3 |
| 48–67% | Поворот | раунд, где ошибаются оба: вопрос зрителю, ответ сразу | П6, С2 |
| 67–82% | Польза | «Но главное в другом — …»: мост к теме канала (ИИ-агент) | Х6 |
| 82–90% | Итог | одно слово на хук («ничья») + по строке на каждого | Ф1 |
| 90–100% | Призыв | подписка | — |
