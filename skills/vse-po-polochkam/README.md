# Всё по полочкам

Собрать личную базу из заметок и конспектов, сделать содержание, найти ответ по источникам и превратить материалы в полезный результат.

Открой чат с ИИ-агентом и отправь этот промт:

```text
Прочитай скилл по ссылке и работай по нему:
https://raw.githubusercontent.com/kuznetsovmark1994/skills/main/skills/vse-po-polochkam/SKILL.md
Помоги собрать мою базу знаний из материалов, которые я дам. Сохрани исходники, сделай содержание со ссылками и проверь ответ по источнику. Затем помоги сделать два полезных результата из моих текстов — по одному за раз. Начни с вопроса, для какой задачи мне нужна база и где лежат материалы, если я ещё этого не сказал.
Если ссылка недоступна, скажи об этом и попроси прикрепить SKILL.md. Не утверждай, что прочитал скилл, пока не открыл его.
```

Дай агенту учебные материалы: выбранную страницу через подключение либо файлы в чате. Для первой пробы достаточно одного конспекта или нескольких заметок.

Если агент не открыл ссылку, [скачай SKILL.md](https://raw.githubusercontent.com/kuznetsovmark1994/skills/main/skills/vse-po-polochkam/SKILL.md), прикрепи к чату и повтори промт. Прикрепление действует в текущем чате; постоянное сохранение зависит от приложения.

Готово, когда исходники сохранены, содержание ведёт к ним, ответ опирается на конкретный источник, а два результата можно использовать в своей задаче.
