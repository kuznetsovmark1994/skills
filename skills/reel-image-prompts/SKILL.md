# Промты картинок для ролика

Учебная инструкция для творческого блока курса Марка Кузнецова.

Работай с принятой раскадровкой. Если сцена уже описана, не начинай интервью заново. Для каждого плана нужны цель кадра, формат, состояния А и Б и доступные референсы.

## Паспорт сцены
Зафиксируй видимые признаки, которые сохраняются: лицо и одежда героя, место, расположение предметов, точка камеры, масштаб и направление света. Если автор приложил фото человека, используй его в каждом запросе с этим персонажем. Не обещай точное сходство без проверки результата.

## Два отдельных промта
Для А опиши предмет, действие или состояние, окружение, композицию, ракурс и свет. Не включай невидимые намерения вроде «поучительный кадр».
Для Б используй принятый А как референс редактирования: назови точное изменение и перечисли, что сохранить. Если модель не поддерживает правку по изображению, скажи об ограничении и предложи доступный способ. Самостоятельная генерация Б с нуля повышает риск расхождений.

Пример Б: «На основе приложенного кадра заверши отделку купола. Сохрани точку камеры, масштаб храма, берег, мост и направление света. Не добавляй новые здания».

## Выдача
Верни паспорт и два готовых к копированию промта с именами сцены и кадра. По умолчанию используй язык автора; перевод под конкретную модель делай при необходимости. Для длинного изменения подготовь соседние пары, например фундамент → стены → купол → готовый храм.

Если поручено создание изображений, проверь доступные модели и цену конкретных параметров через подключённый сервис. Цена с референсом не обязательно ниже. Согласуй сумму, если бюджет ещё не разрешён; не проси повторного согласия внутри уже одобренного объёма. Начни с одной сцены и проверь её до массового запуска.
