# Как дать ИИ доступ к видео и картинке

Сначала используй уже доступный инструмент просмотра или получения видео. Для локального Codex / Claude подходит помощник `scripts/reference.py` из этой же папки скилла. Установи скилл целиком: один открытый SKILL.md не переносит скрипт автоматически.

## Подготовка

Нужны Python 3, Pillow, FFmpeg с ffprobe; для ссылки — yt-dlp. Проверь доступность команд и устанавливай только отсутствующее в подходящую среду проекта. Актуальные инструкции: [FFmpeg](https://ffmpeg.org/download.html), [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation), [Pillow](https://pillow.readthedocs.io/en/stable/installation/basic-installation.html). YouTube иногда требует поддерживаемый yt-dlp JavaScript runtime: следуй текущему сообщению загрузчика.

```bash
python /path/to/reel-reference/scripts/reference.py doctor
python /path/to/reel-reference/scripts/reference.py prepare 'https://www.youtube.com/watch?v=VIDEO_ID' --out project/reference-01
python /path/to/reel-reference/scripts/reference.py prepare '/path/to/video.mp4' --out project/reference-02
```

Укажи реальную ссылку вместо VIDEO_ID. Папка результата должна быть новой. Помощник сохраняет полный источник, описание и SHA-256, звук WAV при наличии, кадры каждые 2 секунды и на сменах сцен, контактные листы с таймкодами. Для длинного видео можно задать `--interval 10`; кадры смен сцен и границы сохраняются. Отчёт о покрытии создаёт агент после просмотра, сам скрипт ничего «не понимает».

Открой все `sheet-*.jpg`, затем важные кадры из `frames/` крупно. Передай `audio.wav` доступному средству распознавания, проверь всю расшифровку и сомнительные места. При наличии нативного просмотра также воспроизведи видео со звуком. Для спорной анимации извлеки более плотную выборку вокруг конкретного таймкода или просмотри отрезок: базовые 2 секунды могут пропустить короткий эффект.

## Instagram и ограниченный доступ

Публичная ссылка иногда требует входа или не отдаёт медиа. Помощник отключает пользовательскую конфигурацию yt-dlp, чтобы сторонние postprocessor/exec-настройки не запускались незаметно. Он не использует cookies и не обходит вход.

При ошибке доступа, 429 или проверке входа останови повторные попытки. Используй приложенный автором файл либо уже разрешённую сессию пользователя через подходящий инструмент. Для cookies потребуется отдельный аккуратный маршрут с авторизацией пользователя; не печатай и не помещай их в репозиторий. Похожий ролик и обложка не заменяют исходник. Если доступен только набор скриншотов, разбери композицию и стиль, а движение и полный сценарий оставь непроверенными.

Исходники, расшифровки и личный профиль сохраняй в проекте пользователя. Не включай их в публичный скилл.
