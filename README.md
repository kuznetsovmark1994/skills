## Как запустить скилл

### С телефона или в обычном чате (Claude, ChatGPT)

Ничего устанавливать не нужно.

1. Открой новый чат.
2. Отправь сообщение со ссылкой из колонки «Ссылка для чата»:

   ```
   Открой эту инструкцию и проведи меня по ней:
   https://raw.githubusercontent.com/kuznetsovmark1994/skills/main/skills/balans-raboty-i-zhizni/SKILL.md
   ```

3. Отвечай на вопросы. В конце получишь результат.

Если ИИ пишет, что не может открыть ссылку (так бывает, когда в чате выключен поиск в интернете), открой ссылку в браузере, скопируй весь текст и вставь в чат.

Скилл работает в пределах одного чата. Чтобы пройти ещё раз, повтори то же самое в новом чате.

### Установить в Claude насовсем

Тогда скилл будет включаться сам, когда скажешь, например, «давай тест на баланс».

1. Скачай архив скилла из папки [`dist/`](dist/) (кнопка Download на странице файла).
2. С компьютера открой claude.ai → Settings → Capabilities → Skills → Upload skill и загрузи архив.

### В Claude Code

```
/plugin marketplace add kuznetsovmark1994/skills
/plugin install balans-raboty-i-zhizni@mark-skills
```

Или просто дай Claude Code ссылку на этот репозиторий и скажи: «поставь отсюда скилл balans-raboty-i-zhizni».

## Как добавить новый скилл

1. Папка `skills/<имя>/` с файлом `SKILL.md` (имя латиницей через дефис).
2. Запись о скилле в [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json).
3. `./tools/build.sh` — пересобрать архивы в `dist/`.
4. Строка в таблицу «Скиллы» выше, со ссылкой raw.
