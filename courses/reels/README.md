# Скиллы для творческого блока

Учебные версии рабочих методов Марка Кузнецова. В комплекте 14 скиллов: от брифа до выпуска ролика. Личные записи, профили, данные аккаунтов, рабочие пути и закрытые материалы автора в комплект не входят.

Сначала берите скилл своего урока. На следующих этапах предыдущие остаются доступны. Проверки встроены в рабочий процесс; для сценария, кадров и монтажа есть отдельные критики.

## Как пользоваться

Дайте ИИ-агенту ссылку на нужный SKILL.md и попросите прочитать инструкцию и связанные материалы. В обычном чате можно приложить файл; если ссылка не открывается, скопируйте текст. В Codex / Claude Code попросите установить соответствующую папку из этого репозитория. Для загрузки скилла в поддерживающий её интерфейс используйте отдельный ZIP. Установка зависит от среды; скилл сам по себе не подключает ElevenLabs, HeyGen или Higgsfield.

Пример запроса: «Используй этот скилл для моего ролика. Сначала посмотри, что уже готово, и начни со следующего нужного шага. Вот материалы: …»

Архив всего набора: [reel-course-kit.zip](../../dist/reel-course-kit.zip). В нём отдельные папки скиллов. Для установки одного скилла берите его собственный ZIP ниже.

## Больше возможностей

[OpenMontage](https://github.com/calesthio/OpenMontage) — дополнительная библиотека. Можно попросить своего ИИ изучить её и выбрать полезные инструменты под конкретную задачу. Для учебного ролика достаточно этого набора.

Видео по ссылке сначала разберите с **reel-reference**: изучаем и речь, и картинку, затем выбираем подходящие приёмы. В монтаже возвращаемся к нему для графики. Помощник в папке скилла готовит видео, звук и кадры; выводы делает ИИ после их просмотра.

## Свои правила

Записывайте выбранный стиль, голос, принятые формулировки и свои правки в проекте ролика. Эти личные настройки не нужно отправлять в публичный репозиторий. Платные действия выполняются в согласованном бюджете; публикация требует поручения автора.
