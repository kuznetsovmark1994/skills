# Всё по полочкам · 7 ноября 2026

Новый ученический скилл `vse-po-polochkam`: первая база знаний, личные акценты,
содержание, проверка ответов по источникам и применение материалов.
Вход — выбранная страница, папка или вложения чата; существующая структура сохраняется.

Добавлены SKILL.md, отдельный ZIP, каталог в README и запись marketplace.
Метод сверён с авторской презентацией и расшифровкой урока о базе знаний.
В публичном пакете нет личных материалов автора и полных текстов урока.

Проверено: quick_validate, редакторская проверка ru_tells, целостность ZIP и
совпадение его содержимого с исходником, git diff --check.
Вручную пройден учебный пример из трёх вымышленных документов: карта, уточнение
даты со ссылками, отсутствие бюджета, сводка решений и вопрос по регламенту.
Скриптом проверены ссылки и неизменность оригиналов. Это проверка примера и
содержания; отдельный независимый запуск модели не проводился.

Инструкция запуска для учеников и копии в папках курса сопровождаются в Notion
и Google Диске. При изменении SKILL.md пересобрать ZIP через tools/build.sh и
обновить обе копии курса. Другие архивы без содержательных изменений не коммитить.
